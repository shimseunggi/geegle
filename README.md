# 🔥 지글 (Geegle) - 인류 역사상 최고의 검색 엔진

지글(Geegle)은 구글(Google)을 패러디한 조선시대 고문 컨셉의 인터랙티브 웹사이트입니다.
마우스 커서가 '인두'로 바뀌며, 숯불에 달궈 죄인을 심문하여 답을 얻어내는 독특한 경험을 제공합니다.

## 🔗 데모 보러가기
👉 **[기글(Geegle) 실행해보기](https://shimseunggi.github.io/geegle/)**
*(위 링크를 클릭하면 웹사이트로 이동합니다)*

## ✨ 주요 특징

### 1. 🖱️ 커스텀 인두 커서
- 마우스 커서가 조선시대 **'인두'** 모양으로 바뀝니다.
- 이미지를 사용하지 않고 **순수 CSS(clip-path)**만으로 인두의 모양과 질감을 구현했습니다.

### 2. 🔥 리얼한 열전도 시스템
- **상태 관리**: 인두는 평소에 차가운 상태입니다.
- **상호작용**: 화면 속 **숯불 화로**에 인두를 가져다 대면, 인두 끝부터 손잡이까지 서서히 시뻘겋게 달아오릅니다 (CSS Gradient Animation).

### 3. 😱 죄인 심문 (검색 기능)
- 달궈진 인두로 죄인을 클릭하면 심문이 시작됩니다.
- 죄인은 화들짝 놀라며(화면 진동 효과) 랜덤한 답변을 이실직고합니다.
- 인두가 식어있으면 심문을 할 수 없어 다시 달궈와야 합니다.
